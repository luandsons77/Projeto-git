Projeto Git - Laboratório

Prática de controle de versão com Git e integração com GitHub.

Sobre o projeto

Este projeto foi criado para demonstrar o uso de controle de versão, incluindo commits, histórico, alterações, staging, diff e revert.

Controle de versão

O Git permite registrar a evolução de um projeto, identificar alterações e retornar a estados anteriores sem apagar o histórico.

Git + GitHub

O repositório local será conectado ao GitHub para publicação e acompanhamento do histórico do projeto.
